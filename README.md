## What it does

`main.py` writes one line of text (1–240 characters) to `/output/entry.txt`:
a quiet, earned moment of pride — a seventy-two-year-old woman finally
riding her bicycle past the corner store after a year of falling off
in the driveway.

## Run

```sh
python3 main.py
```

Deterministic, no network access, no randomness. Running it twice
produces byte-identical output.
